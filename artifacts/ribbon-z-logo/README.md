# Ribbon Z — reference reconstruction

Created from the supplied reference. The final artwork preserves its asymmetric silhouette, swept terminals, split diagonal, folded faces, and fine grayscale highlights. The reference's corner captions and background are excluded from the logo.

## Files

- `ribbon-z.svg`: detailed vector reconstruction of the supplied artwork, with a transparent background. Its 61 grayscale tonal layers preserve the reference shading; no raster image is embedded. Keep these layers together when scaling the mark.
- `ribbon-z.png`: 2400 × 2400 transparent PNG rendered from that SVG.
- `ribbon-z-flat.svg`: compact, single-color version of the same original silhouette.
- `ribbon-z-flat-white.svg`: white version for dark backgrounds.
- `preview.png`: the detailed mark on a clean light-gray presentation background.
- `size-checks.png`: exported SVG checks at 24, 48, and 128 px, including a reversed silhouette.
- `ribbon-z-assets.zip`: the complete asset package.

The SVG uses the original 1200 × 1200 coordinate system and retains the reference's proportions and placement. Its diagonal gap is real transparency. The detailed SVG contains more vector geometry to preserve the source shading; use the compact flat versions when a single-color mark is appropriate. At tiny sizes, the fine highlight lines naturally disappear.
